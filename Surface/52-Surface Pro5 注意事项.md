# Surface Pro5 注意事项

## 1. 网卡下载速度慢&经常断流

Surface Pro 5（第 5 代）使用的无线网卡为 **Marvell AVASTAR Wireless-AC Controller**。这颗网卡在电源管理和驱动兼容性上存在已知缺陷，常表现为休眠唤醒后断网、高负载下掉线或 Ping 值忽高忽低。

#### 1. 关闭电源省电策略（最有效）

网卡断流多是因为系统为了省电强制关停了网卡模块。

- **步骤 1**：按 `Win + X` 打开菜单，选择 **设备管理器**。
- **步骤 2**：展开 **网络适配器**，找到 **Marvell AVASTAR Wireless-AC Network Controller**，右键选择 **属性**。
- **步骤 3**：切换到 **电源管理** 选项卡，**取消勾选**“允许计算机关闭此设备以节约电源”，点击确定。
- **注**：若该选项卡缺失，可按 `Win + R` 输入 `regedit`，前往 `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Power`，将 `CsEnabled` 的值修改为 `0` 并重启电脑。

#### 2. 禁用蓝牙与 Wi-Fi 模式调整

Marvell 网卡将 Wi-Fi 与蓝牙集成在同一芯片上，两者频段易发生干扰导致断流：

- **关闭蓝牙测试**：在任务栏或设置中暂时关闭蓝牙，观察 Wi-Fi 是否恢复稳定。
- **锁定 5GHz 频段**：
  1. 在设备管理器中再次右键 **Marvell AVASTAR** 选择 **属性**。
  2. 进入 **高级** 选项卡，找到 **Band** 或 **Preferred Band**。
  3. 将值由 `Auto` 改为 `5GHz Only` 或 `Prefer 5GHz`（避免在 2.4G/5G 频段间频繁切换造成切网跳 ping）。

#### 3. 重置网络与驱动回退/更新

- **彻底重置网络**： 以管理员身份运行 PowerShell 或 CMD，依次输入以下命令后重启：

  DOS

  ```
  netsh winsock reset
  netsh int ip reset
  ipconfig /flushdns
  ```

- **驱动处理**：

  - **回退默认驱动**：在设备管理器的网卡属性中选择 **驱动程序** -> **更新驱动程序** -> **浏览我的电脑以查找驱动程序** -> **让我从计算机上的可用驱动程序列表中选择**，尝试切换为 Windows 内置的早期版本。
  - **微软官方固件包**：前往微软官网下载 Surface Pro 5 的官方驱动包 (`SurfacePro_Win10_18362_20.034.43157.0.msi` 或最新版) 进行覆盖安装。

#### 4. 终极替代方案（硬件绕过）

若芯片硬件老化或发热脱焊，软件层面很难完全根治，可考虑以下物理替代方案：

- **使用 USB 无线网卡**：购买体积较小的迷你 USB 无线网卡（如绿联、TP-Link 的免驱微型网卡），插入 USB 接口使用，并在设备管理器中**禁用**原厂 Marvell 网卡。
- **拓展坞有线网口**：使用带有 RJ45 千兆网口 Mini DisplayPort 或 USB 拓展坞，改用有线连接。

#### 5. 禁止网卡节能

修改注册表禁用网卡节能，这是解决 Marvell AVASTAR 网卡自动降速/断流最彻底的方法。

1. 按下快捷键 `Win + R`，输入 `regedit`，按回车打开 **注册表编辑器**。
2. 在顶部地址栏中直接粘贴并转到以下路径：

   ```Plaintext
   HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Class\{4d36e972-e325-11ce-bfc1-08002be10318}
   ```
3. 打开后，你会看到该路径下有一堆形如 `0000`、`0001`、`0002` 的文件夹。
4. 依次点击这些文件夹，看右侧列表中是否有 **`DriverDesc`** 这一项，且数值数据显示为 **`Marvell AVASTAR Wireless-AC Network Controller`**（通常在 `0001` 或 `0002` 中）。
5. 找到对应的文件夹后，在右侧空白处右键点击 $\to$ **新建 $\to$ DWORD (32位)值**。
6. 将名称重命名为：**`TxPowerControl`**。
7. 双击打开它，将 **数值数据修改为 `1`**（十六进制），点击确定。
8. **重启电脑**，即可生效。

### 1.2 修理（重焊）

这台 `Surface Pro5` 正好需要**拆屏换电池**，既然**最难、风险最大**的步骤（拆屏）需要解决。**务必让维修师傅在换电池的同时，顺手对 Marvell 网卡芯片进行加热加焊或更换**。这样不仅能让电池回血，还能让这台唯一“瘸腿”的 Surface Pro 5 重新恢复完美的无线网络！

#### **1.2.1 虚焊修复的方法（补焊 / 加焊）**

Surface Pro 5 的 Marvell AVASTAR 网卡芯片是 **BGA 封装（焊珠在芯片底部）**，直接焊接在主板上。如果是由于长期发热或微小摔碰导致的虚焊，专业维修店有两种处理方式：

- **加焊（热风枪植焊/BGA加焊）**： 师傅在拆开主板后，往网卡芯片缝隙注入焊油，使用热风枪加热让底部的焊点重新熔融结合。**这种方法速度最快、成本最低。**
- **重做 BGA（植珠）**： 如果加焊不行，就需要把网卡芯片彻底取下来，清理焊盘、重新铺上新的锡珠（植珠），再焊接回去。

#### **1.2.2 顺便维修的最优策略：重焊 vs 直接换主板**

在去维修店换电池时，你可以这样和师傅沟通：

- **策略 A（优先）：顺手加焊网卡芯片**
  - 既然主板已经裸露出来了，让师傅用热风枪顺便给 Marvell 芯片“吹一下”加焊，通常只需**顺手加收极少的工时费**（甚至有些熟练师傅会顺手帮吹）。吹完后当场插电测试大流量下载，如果恢复正常，就彻底根治了。
- **策略 B（终极备选）：直接打风枪换一颗网卡芯片**
  - 如果加焊后还是断流，说明不是简单的虚焊，而是芯片内部已经热击穿损坏。淘宝/拆机市场上的 Marvell AVASTAR 芯片本身非常便宜（几块到十几块钱），师傅可以直接换一颗全新的芯片上去。

#### **1.2.3 给师傅交待的注意事项**

1. **先断开电池电源，再动热风枪**： 换电池时必须先断开主板接口，绝对不能带电进行任何焊接操作。
2. **注意芯片周围的屏蔽罩与散热胶**： 网卡芯片附近有屏蔽罩，焊接时需要注意控温，避免吹掉周围的微型电容电阻。
