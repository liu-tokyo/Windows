

## Surface 存在的普遍问题

| 型号         | 问题                                         | 备注                                                         |
| ------------ | -------------------------------------------- | ------------------------------------------------------------ |
| Surface Pro3 | Simplo / LG 电池逻辑门与急速老化（最著名）   | 设备使用一段时间后，电池容量在短时间内急速暴跌，脱离电源即关机。 |
| 〃           | 散热设计不足与“发热降频/风扇狂转”            | 只要进行稍微繁重的任务，机身右上角就会剧烈发热；             |
| 〃           | Marvell 芯片引起的 Wi-Fi/蓝牙断流与休眠耗电  | 休眠唤醒后经常显示“无 Internet 连接”或直接找不到 Wi-Fi 列表；开启蓝牙设备（如蓝牙鼠标/音箱）时，Wi-Fi 延迟剧增甚至断网。 |
| 〃           | 黄斑屏与触摸失灵（黄线/死区）                | 长时间高温运行导致屏幕边缘的胶水老化变质，显示白色背景时会出现明显的黄色斑块。 |
| 〃           | 支架阻尼铰链磨损与易碎的屏幕玻璃             | 无级铰链耐用度一般，频繁使用后阻尼会明显下降，稍微用力按压屏幕支架就会自动滑开。 |
| Surface Pro4 | 屏幕热抖动与闪烁（Flickergate）              | 非常著名的硬件缺陷问题，主要源于屏幕控制芯片/LCD 面板的硬件设计缺陷。<br />※ 更换 Surface Pro 5 (SP5) / Pro 6 的屏幕* |
| 〃           | 电池膨胀顶开屏幕（鼓包门）                   | 机身侧面或屏幕边缘出现明显的缝隙甚至漏光，严重时电池膨胀直接将整个玻璃屏幕“挤压撬开”并翘起。 |
| 〃           | Sleep of Death（睡死门 / 睡眠发热耗电）      | 合上键盘盖或按电源键休眠后，设备无法被唤醒，只能长按电源键强制重启；或者放在背包里休眠时，机身无故剧烈发热，几小时内耗尽全部电量。 |
| 〃           | 幽灵触控与触控死区（Phantom Touch）          | 没有碰触屏幕，屏幕上却会自动出现大量“小圆点”并随机点击；或者屏幕特定区域（特别是发热严重的区域）失去触控响应。 |
| 〃           | NVMe 固态硬盘与显卡驱动崩溃（初期问题）      | 频繁出现蓝屏死机（BSOD）、驱动重置或者休眠唤醒后提示找不到存储设备（SSD 丢失）。 |
| Surface Pro5 | Marvell AVASTAR 无线网卡断流与休眠丢包       | 这颗网卡在电源管理和驱动兼容性上存在已知缺陷，常表现为休眠唤醒后断网、高负载下掉线或 Ping 值忽高忽低。 |
| 〃           | 无风扇版本（m3/i5）过热剧烈降频与膨胀        | 虽然日常办公极度安静，但只要运行较长时间的高负载任务，由于被动散热积热严重，CPU 频率会瞬间断崖式下跌（最低降频至 0.8GHz 甚至更低），导致系统极度卡顿。 |
| 〃           | 电池老化鼓包（撬开屏幕/机身变形）            | 屏幕边缘出现挤压漏光、黄色斑块，严重时电池膨胀会直接把玻璃屏幕从机身骨架上“撬开”顶出缝隙。 |
| 〃           | 睡眠死机（Sleep of Death / 睡眠发热）        | 按电源键或合上键盘盖进入休眠后，设备无法被再次唤醒，只能长按电源键 15 秒强制重启；或者设备放在背包里休眠时无故异常发热，短短几小时内将电量消耗殆尽。 |
| 〃           | 屏幕黄斑与触控死区（Phantom Touch）          | 发热较高的区域（屏幕四周或边缘）在显示白色背景时出现明显的黄色变色斑块；或者没碰屏幕时自动出现点击小圆点（幽灵触控），部分区域失效。 |
| Surface Pro6 | CPU 剧烈降频至 0.40GHz（BDPROCHOT 错误锁频） | 无论设备是在闲置状态还是在高负载运行，CPU 主频会突然断崖式下跌并**锁定在 0.40GHz（400MHz）**，导致整个系统变得极度卡顿、鼠标掉帧，甚至连打字都有延迟。<br />※ 可通过第三方软件（如 ThrottleStop）取消勾选 `BDPROCHOT` 选项，绕过该信号强制恢复 CPU 频率。 |
|              | Marvell AVASTAR 网卡掉线与断流（老毛病）     | SP6 依然沿用了那颗饱受诟病的 **Marvell AVASTAR 无线网卡**（直至 SP7 才终于换成了 Intel 网卡）。 |
|              | 电池老化鼓包（撬开屏幕/机身变宽）            | 机身侧面或屏幕边缘出现明显的挤压缝隙、漏光或黄色斑块，严重时电池膨胀会直接把玻璃屏幕从机身骨架上“撬开”顶出。 |
|              | 键盘盖触点氧化与无法识别（Type Cover 掉盘）  | 键盘盖经常失效、按键无响应、背光熄灭，或提示“未连接键盘”。通常需要多次反复插拔，甚至调整角度才能重新识别。 |
|              | 接口配置落后（缺乏 USB-C 接口）              | 同期的 Surface Go 都已配备 USB-C，但 SP6 依然固执地保留了古老的 **Mini DisplayPort** 和 **USB-A** 接口，不支持 USB-C PD 通用快充，外出必须携带专用且笨重的 Surface Connect 磁吸充电线。 |
|              | 可维修性极差（iFixit 评分仅 1/10）           | 一旦遭遇电池膨胀、SSD 损坏或屏幕破裂，极难进行局部维修。     |
